# Chrome Web Store listing — CleanZoom

## Name
CleanZoom — Hover to Enlarge Images

## Summary (132 char max)
Hover any thumbnail to instantly preview the full-size image. No tracking, no accounts — nothing ever leaves your browser.

## Category
Productivity

## Description
Stop clicking into images just to see them properly. CleanZoom shows the
full-size version the moment you hover a thumbnail — on shopping sites, image
boards, social feeds, galleries, search results, and just about anywhere else.

WHY CLEANZOOM
• Instant, full-resolution previews on hover
• Works with thumbnails, image links, srcset, lazy-loaded galleries, and CSS backgrounds
• Shows the real pixel dimensions of every image
• Only previews when a bigger image actually exists — no pointless re-zoom
• Tune the hover delay, require a hold-key (Alt/Shift/Ctrl), or cap the size
• Turn it off per-site with one click

PRIVATE BY DESIGN
CleanZoom makes zero network requests of its own. No analytics. No accounts.
No data collection of any kind. It asks only to remember your settings. The
images you preview load straight from the site you're already on — nothing is
ever sent to us, because there is no "us" server to send it to.

This is the clean, honest hover-zoom: built for people who remember when image
preview extensions got bought out and turned into spyware. Never again.

## Permission justifications (for the submission form)
- storage: Save the user's own preferences (hover delay, activation key, max
  size, per-site disable list). No browsing data is stored.
- Host permissions / content script on all sites: Required so the preview can
  appear on whatever page the user is viewing. Used only to detect a hovered
  image and render its larger version locally. No page content is read,
  recorded, or transmitted.

## Single purpose
Display a larger preview of an image when the user hovers its thumbnail.
